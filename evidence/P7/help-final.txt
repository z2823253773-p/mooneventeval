MoonEventEval 0.1.0
Usage:
  mooneventeval import-tsv REFERENCE --prediction PREDICTION [--format json]
  mooneventeval evaluate FILE [--format text|json]
  mooneventeval explain-pair FILE --recording ID --reference ID --prediction ID [--format text|json]
  mooneventeval --help
  mooneventeval --version
Input: JSON tasks for evaluate/explain-pair; two headered TSV files for import-tsv.
Output: evaluate/explain-pair default text; import-tsv JSON task. Files are read only.
Exit: 0 completed; 2 input/argument/file; 3 resource limit; 4 internal.
