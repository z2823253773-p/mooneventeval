# 供本人复算的八个小例子

来源：本项目AI辅助构造及精确十进制算术，不是第三方权威期望或用户已完成的手算。每一行先由参赛者在运行产品前独立复算，填写核对记录；不能让产品结果反向决定期望。

| 编号 | 条件与输入 | 算式/独立预期 | 本人复算 |
| --- | --- | --- | --- |
| E1 重复 | 默认c=0.2,q=0.5；r=[10,12]；p1=[10,12]，p2=[10.05,12.05] | 两者可连一个参考，匹配至多1且能达到1；TP1/FP1/FN0；P=1/2,R=1,F1=2/3 | 未进行 |
| E2 贪心陷阱 | r1=[10,11],r2=[10.3,11.3]；p1=[10.15,11.15],p2=[9.85,10.85] | 起点差0.15/0.15/0.15/0.45；r1-p2、r2-p1合法，TP2/FP0/FN0；朴素先到先配可只得1 | 未进行 |
| E3 起点等号 | r=[10,12]；分别单放p=[10.2,12.2]、[10.200001,12.2] | 起点0.2≤0.2与0.200001>0.2；前者TP1，后者TP0/FP1/FN1 | 未进行 |
| E4 比例主导终点 | r=[10,12]；分别单放p=[10,13]、[10,13.000001] | max(0.2,2×0.5)=1；终点1合格，1.000001不合格 | 未进行 |
| E5 固定容差主导 | r=[10,10.1]；分别单放p=[10,10.3]、[10,10.300001] | max(0.2,0.1×0.5)=0.2；终点差0.2合格，0.200001不合格 | 未进行 |
| E6 参考时长不对称 | r=[10,12]，p=[10,13.1] | 参考时长2给容差1，差1.1不合格；错用预测时长3.1会给1.55并误判 | 未进行 |
| E7 错类同时间 | r为A类[1,2]，p为B类[1,2]，均声明类别 | 标签不等，无边，TP0/FP1/FN1；sed_eval原始全局另有substitution口径，须区别 | 未进行 |
| E8 分数微秒 | c=0,q=0.5；r=[10,10.000003]；分别单放p=[10,10.000004]、[10,10.000005] | 容差3µs×0.5=1.5µs；1µs合格，2µs不合格；不能取整容差 | 未进行 |

这些例子减少完全依赖同一oracle代码的风险，但仍来自同一规格，不能消除共因失效。进一步证据需要原版参考实跑、独立评审和本人真实复算；八行均不冒充已执行产品测试。
